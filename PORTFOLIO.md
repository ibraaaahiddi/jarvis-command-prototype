## JARVIS Command Prototype

A small, public Python prototype that turns one instruction into one simple local task.

**Proof:** https://github.com/ibraaaahiddi/jarvis-command-prototype

- Commands: create a folder, list files, write a timestamped note, open a safe http(s) URL, and optionally take a screenshot.
- Safety: local workspace sandbox, validated folder names, path-traversal checks, and http(s)-only URL validation.
- Quality: six unit tests, a README, and a clear “not the full assistant” scope.
- Why it matters: demonstrates command parsing, safe execution boundaries, CLI design, testing, and documentation.

## Documentary Production & QA

A 12:59.97 archival documentary project, produced and QA'd under a stage-gated workflow.

- 1920×1080, 30 fps, H.264/AAC; 23,399 frames; 170 shots; 58 unique assets.
- 318 caption groups / 1,532 words, burned-in plus SRT, no overlaps.
- Final QA: 0 render errors, 0 missing files, 0 frame seams, 6 spot stills reviewed.
- Source rules: public-domain/CC0/owned assets, honest labels, no music or instruments, human media review before publishing.
- Tools: Remotion, OpenMontage, FFmpeg/ffprobe, caption and source-review pipelines.
